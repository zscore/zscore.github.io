  • sunflower composition

    2026

    Four animated sunflower fields, each one a single C file that writes raw RGB frames to stdout — no libraries, no assets, nothing but arithmetic. One piece opens and shuts the heads to draw a cat as a halftone; the others drive them from superposed wave fields, and one of those is rebuilt under the rule that no flower may ever move quickly, which turns out to be a design principle rather than a tax.

    live repo C generative art wave physics

  • ethereal jungle

    2026

    A generative audiovisual set where the music and the visuals are siblings rather than parent and child. Strudel drives the pattern engine, superdough renders the audio, and three.js draws a four-storey forest on WebGPU — but the visualizer never reads the audio. Both sides read the same control bus, so one brightness walk moves the mode ladder and the camera altitude at once.

    instagram repo JavaScript three.js WebGPU Strudel

  • flat cats

    2026

    Eighty cat photographs, every one CC0 or public domain, segmented twice over — once cut from the background and once split into body parts. The scraper re-checks each file's own licence metadata rather than trusting the search filter. The corpus feeds a browser piece scored to Easley Blackwood's seventeen-note microtonal etude.

    instagram repo JavaScript Python corpus

  • white dots on black

    2026

    An interactive tool for making pictures in the manner of Sigmar Polke's Dublin series — fields of white dots on a dark ground, tuned by size, density and distribution until the thing tips from order into something closer to weather.

    live repo JavaScript generative art

  • Wortzusammensetzungsmaschine

    2026

    A game about the one thing German is famous for. Pick your starting pieces, stack compounds as far as the dictionary will let you, and find out afterwards how much longer a word you could have built.

    live repo JavaScript German games

  • bjj-rag

    2026

    Retrieval over a few years of Brazilian jiu-jitsu training notes. Sessions are parsed into structured records, chunked, embedded and indexed incrementally, then queried in plain language. A second agent skips retrieval entirely and runs sandboxed code against the sessions as a dataframe when the question is really about trends.

    repo Python RAG ChromaDB

  • A/B testing for fraud detection

    2025

    A talk on running experiments where the thing you are measuring fights back. It walks from choosing metrics and experimental units through power analysis and champion–challenger rollouts, then into the parts that are peculiar to fraud: labels that mature long after the decision, data censored by the blocks you made, and the randomised exploration you need to see through it.

    slides statistics talk fraud detection

  • workout logger

    2025

    Talk your way through a workout and have it land in a spreadsheet. A custom GPT calls an OpenAPI-described Cloud Function, which appends the set to a Google Sheet through a service account — so the logging happens in the same conversation as the excuses.

    medium repo Python Google Cloud OpenAPI

  • codenames embeddings

    2023

    A spymaster built out of word vectors. Given a board, it searches fastText embeddings for the single word closest to the agents it wants and far from the ones that end the game — which turns out to be a legible demonstration of what embedding space actually knows about words.

    medium repo Python fastText NLP

  • L-systems for language

    2017

    L-systems usually grow plants. This one grows sentences: part-of-speech trigrams pulled from a corpus become rewrite rules, and each generation expands the last into something longer and stranger but still grammatical at the seams.

    live write-up repo JavaScript NLTK generative text

  • testing many hypotheses at once

    2017

    A talk given at trivago on what goes wrong when you run a lot of tests and only report the interesting ones — and which corrections are worth the power they cost. The slides are live; the notebook behind them is in the repo.

    live statistics talk reveal.js

  • bicycle pavement data

    2016

    Accelerometers on handlebars, ridden around Chicago to work out which streets are actually rough. Noisy GPS trails get snapped to street segments and the shaking gets filtered into a pavement rating, with a routing engine on top. The write-up is as much about what stalls a project like this — riders, ground truth, money — as about the signal processing.

    write-up analysis app routing docs Python Jupyter GIS

  • rapid response team assignment

    2016

    A linear program, written in Julia with JuMP, for assigning CDC rapid response teams to where they are needed. Done at my father's request, which is a reasonable way to end up learning a solver.

    Julia JuMP optimization
